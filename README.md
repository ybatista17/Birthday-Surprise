# Blue Bahama Journal

A birthday garden journal for a *Passiflora caerulea* ‘Blue Bahama’ living in a New York apartment: a care almanac, a watering log, and the road to her first flowers in summer 2027.

Header artwork: *Passionflower*, colored pencil, 2020, by Laura Cruz-Albrecht.

Hosted with GitHub Pages from `index.html`. Watering logs and milestones are saved in the browser on each device.
